# Student Grade Tracker

## About the Project
Student Grade Tracker is a Java console-based application that helps manage student marks and generate a performance summary for each student.

## Features
- Stores multiple students and their names.
- Accepts multiple subjects and their marks.
- Validates marks between 0 and 100.
- Calculates total marks and average marks.
- Displays the highest and lowest marks for each student.
- Displays a summary report for every student.

## Technologies Used
- Java
- ArrayList
- Arrays
- Loops and conditional statements
- Scanner class

## How to Run
1. Install the Java Development Kit (JDK).
2. Open the project folder in your terminal.
3. Compile the program:

   `javac StudentGradeTracker.java`

4. Run the program:

   `java StudentGradeTracker`
